# Gesture Controlled Presentation System

A computer vision based presentation control system built using Python, OpenCV, MediaPipe, and PyAutoGUI.

## Features

- Hand gesture recognition
- Swipe left/right for slide navigation
- Virtual laser pointer using finger tracking
- Real-time webcam processing
- PowerPoint/Slides control

## Technologies Used

- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- NumPy

## Controls

| Gesture | Action |
|---|---|
| Swipe Left | Next Slide |
| Swipe Right | Previous Slide |
| Index Finger Up | Laser Pointer Mode |

## Installation

Clone the repository:

```bash
git clone https://github.com/rosa-7/gesture-presentation.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```
