# Gesture Controlled Presentation System

A computer vision based presentation control system built using Python, OpenCV, MediaPipe, and PyAutoGUI.

## Features

- Real-time hand tracking
- Gesture recognition using MediaPipe
- Swipe left/right for slide navigation
- Webcam-based presentation control
- PowerPoint/Google Slides navigation

## Technologies Used

- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- NumPy

## Controls

| Gesture | Action |
|---|---|
| Swipe Left | Next Slide |
| Swipe Right | Previous Slide |

## Installation

Clone the repository:

```bash
git clone https://github.com/rosa-7/gesture-presentation.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```
